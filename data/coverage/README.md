# Coverage Check

Check was done 8/23/26 to assess data completeness (coasters and parks tables specifically).

Coverage report in `./report.txt` generated by `scripts/src/check-coverage.ts`.
Structured queue in `./queue.json` and summary in `./queue-summary.md`, generated by
`scripts/src/build-coverage-queue.ts`.
Human triage handoff in `./master-triage.md`, also generated by
`scripts/src/build-coverage-queue.ts`.
Manual queue overrides live in `./queue-overrides.json` and are keyed by report line number
(`queue.json[].lineNumber`), not by `queue-summary.md` line number.
Park alias corrections for the checker live in `./park-aliases.json`.
