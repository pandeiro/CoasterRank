# Documentation

CoasterRank documentation is organized by purpose:

- [`PLAN.md`](PLAN.md) is the authoritative architecture, decision, and delivery plan.
- [`SECURITY.md`](SECURITY.md) describes the security posture and trust boundaries.
- [`product/`](product/) contains product specifications, including the guest onboarding flow.
- [`architecture/`](architecture/) contains current system design, scaling notes, and adopted architecture decisions.
- [`operations/`](operations/) contains runbooks and synthetic-data procedures.
- [`research/`](research/) contains future-facing strategy proposals and reproducible measurements.
- [`design/`](design/) contains accepted visual decisions and brand sources.
- [`reference/`](reference/) contains generated schema and RPC snapshots. Do not hand-edit it.
- [`previews/`](previews/) contains UX review screenshots retained for PR references.
- [`social-preview/`](social-preview/) contains source HTML and generated social-card assets.

Historical brainstorming and one-off review artifacts are removed rather than kept in a generic archive.
