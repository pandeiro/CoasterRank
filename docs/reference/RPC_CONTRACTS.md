## Reading This Document

- **Execute grants** are the database roles allowed to call the function through PostgREST.
- **Security** is the PostgreSQL execution mode: `definer` runs with the function owner's privileges; `invoker` runs with the caller's privileges.
- The signature shows identity arguments (defaults omitted); the Arguments row shows the full declaration with defaults.
- **Called by** lists repo files with a literal `.rpc('name')` call. **Invoked by** (pipeline sections) lists Edge Function / script / migration references plus the `pg_cron schedule` marker.
